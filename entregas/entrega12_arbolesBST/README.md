# Semana 12 - Gestor de Inventario Jerarquico (BST)

## Descripcion
BST donde cada nodo es un Producto (id, nombre, stock).
Implementa insercion y busqueda por ID, y suma recursiva del stock total.

## Estructura
- `src/dominio/Producto.java` — modelo de datos
- `src/dominio/BST.java`      — arbol binario de busqueda
- `src/aplicacion/Main.java`  — demo de insercion, busqueda y stock total
- `src/test/BSTTest.java`     — tests JUnit 5

## Uso
build.bat run
