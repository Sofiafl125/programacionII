# Semana 11 - Diccionario de Sinonimos (Tabla Hash)

## Descripcion
Tabla hash propia con encadenamiento para colisiones.
Clave: String (palabra). Valor: List<String> (sinonimos).
Incluye comparacion de tiempo de busqueda frente a ArrayList.

## Estructura
- `src/dominio/TablaHashSinonimos.java` — tabla hash con encadenamiento
- `src/aplicacion/Main.java`            — demo y comparacion de tiempos
- `src/test/TablaHashSinonimosTest.java` — tests JUnit 5

## Uso
build.bat run
